# 1. Бинарный поиск (LeetCode 704)

- **Занятие:** 2. Бинарный поиск (2026-10-03)
- **Сложность:** лёгкая
- **Решал на паре:** Музыкант Родион

## Условие

Дан список `nums`, отсортированный по возрастанию, без повторов, и число `target`. Верните индекс `target` в `nums` или `-1`, если его там нет.

Решение должно работать за $O(\log n)$.

| вход | выход |
|---|---|
| `nums = [-1, 0, 3, 5, 9, 12]`, `target = 9` | `4` |
| `nums = [-1, 0, 3, 5, 9, 12]`, `target = 2` | `-1` |

Оригинал: [leetcode.com/problems/binary-search](https://leetcode.com/problems/binary-search/).
