Для того чтобы алгоритм мог работать с сущностями реального мира (автомобили, тексты, биологические клетки), их необходимо формализовать.

**Признак** — это результат измерения определенной характеристики объекта. Совокупность всех измеренных признаков образует **признаковое описание** (обычно это вектор в многомерном пространстве).

#### 1. Бинарные признаки

Принимают всего два значения. Обычно используются для обозначения наличия или отсутствия какого-либо свойства.

- **Кодирование:** $\{0, 1\}$ или $\{-1, 1\}$.
    
- **Примеры:** наличие аудиосистемы в машине (да/нет), биологический пол, заряд частицы (+/-).
    

#### 2. Категориальные признаки

Принимают значения из некоторого конечного множества (дискретные значения). Делятся на два подтипа:

- **Номинальные:** Значения нельзя сравнивать между собой («больше» или «меньше»), только на равенство.
    
    - _Примеры:_ цвет кузова, марка автомобиля, город проживания. Фраза «синий > красный» не имеет смысла.
        
- **Порядковые (Ранговые):** Значения имеют естественный порядок, их можно сравнивать, но нельзя математически точно измерить «расстояние» между ними.
    
    - _Примеры:_ воинские звания (майор > сержант), оценки в школе (отлично > хорошо), уровень удовлетворенности сервисом.
        

#### 3. Числовые (Непрерывные) признаки

Самый распространенный тип. Представляют собой результаты измерений, выраженные действительными числами из определенного диапазона.

- **Специфика:** С ними можно выполнять любые арифметические операции (складывать, вычитать, находить среднее).
    
- **Примеры:** масса объекта (800 кг, 799.54 кг), пробег автомобиля, температура воздуха, доход пользователя.
    

#### 4. Географические данные

Специфический тип данных, представляющий собой координаты (широта и долгота) на поверхности Земли.

- **Специфика:** Требуют особых методов обработки (например, вычисление расстояния между точками с учетом кривизны планеты).
    
- **Применение:** Задачи логистики, сервисы такси, геомаркетинг.
    

#### 5. Данные о дате и времени (DateTime)

Описывают момент наступления события или его длительность.

- **Специфика:** В библиотеках (например, _pandas_) выделяются в специальный тип. Позволяют извлекать циклические признаки: день недели, час суток, месяц.
    
- **Применение:** Работа с временными рядами, финансовые прогнозы, анализ сезонности спроса.
